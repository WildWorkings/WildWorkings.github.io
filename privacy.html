Privacy Policy

Wild Workings Uploader. Last updated: 25 November 2026

Who uses this app

Wild Workings Uploader is a private desktop tool used only by the owner of the Wild Workings YouTube channel. It is not offered to the public.

What data the app accesses

With the channel owner's permission (Google OAuth), the app uses the YouTube Data API to upload videos, set video metadata and thumbnails, schedule publication, and update the channel description and keywords. It only accesses the channel owner's own YouTube account.

How data is stored

The OAuth access token is stored only on the channel owner's own computer. The app has no server and no database. It does not send data anywhere except to Google's YouTube API.

Sharing

No data is sold, shared with third parties or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is subject to the YouTube Terms of Service and the Google Privacy Policy.
